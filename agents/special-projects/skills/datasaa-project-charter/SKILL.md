# datasaa-project-charter

```markdown
# Charter: <project>
Outcome:     the result, in one sentence
Why now:     the problem it removes, with source
Boundary:    systems it may change; systems it may only read
Done when:   observable checks
Gates:       who approves what
Promote to kit when: proven on one live client, with the record linked
```
