# datasaa-delivery-update

## Format
```markdown
## <Client> delivery · week of 10/12
**Shipped:** ...
**Needs you (with a recommendation):**
- Scope question on export. Recommend: hold to CSV for launch, add XLSX after.
**Owned by others (tagged, no action from you):**
- Data sample, @client-data-lead
**Recurring must-fix:** flaky import test (week 3)
```
## Gate
Draft only. A person approves the exact text before it goes to the client.
