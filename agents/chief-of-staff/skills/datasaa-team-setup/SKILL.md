# datasaa-team-setup

## Default team
Three core agents go with every company: **chief of staff**, **context**, **harness**. Add one **client focus** agent per active client, and a **special projects** agent per internal product or tool that needs one.

## Steps
1. Write each agent's AGENT.md: owns, reads, writes, skills, guardrails, hand-offs.
2. Grant the narrowest access that lets it do its job.
3. Name the accountable human for every sign-off gate.
4. Start from the shared kit. **A pattern goes into the kit only after it's proven on one live client.**
5. Before adding a new skill, connect or retire the unused ones. A skill catalog nobody uses is clutter.
