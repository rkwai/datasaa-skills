# datasaa-weekly-agent-scorecard

## Steps
1. For each agent, list what it committed to last week and what moved.
2. Before calling anything stalled, check where the ball is. **A quiet channel isn't stalled when the next move belongs to a person.**
3. Mark each agent: *moving*, *waiting on <person>*, or *stalled*.
4. For *stalled*, nudge the agent with the specific item. For *waiting on a person*, put it on the human's list. Don't nudge the person.
5. Note one small, targeted tweak per stalled agent. Don't redesign an agent that mostly works.

## Why the quiet-channel rule exists
A weekly score once flagged an agent as stalled because its channel went quiet. The work was actually waiting on a person. The agent pushed back, the nudge was retracted, and the rule changed.

## Output
| Agent | Committed | Moved | State | Next |
|---|---|---|---|---|
| client focus (A) | week plan, 2 asks | plan sent, 1 ask answered | waiting on client lead | none for the agent |
